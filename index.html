Never stare at a dead chat again.

Claude Code is a program that chats with you and writes code with you, like a tutor typing alongside you. 01

The wall you hit mid-sentence

Why does this need to exist? ›

Picture chatting with a coding assistant that writes code right alongside you.

You're deep in a project, and the assistant is helping you write code. Every message counts toward a limit on your account. That limit works like a stopwatch — it quietly resets every few hours.

Hit the limit, and the assistant goes silent until the stopwatch runs down. You could open a second account in another window. But you have to notice your first stopwatch is running low, stop what you're doing, and switch over by hand — every single time, all day.

Running two accounts at once is worse. You're tracking two stopwatches in your head. One careless slip logs you out of the wrong one mid-task.

02

A spare account, ready the second you need it

What is it, concretely? ›

claude-swap is built for anyone who uses a coding assistant so much that one account isn't enough.

It keeps several of your accounts standing by, each with its own stopwatch and its own leftover time. You can jump to any of them by hand, in one step, without logging out first.

It also shows a live dashboard — every account's used-up percentage and reset time, all on one screen, like a fuel gauge for each login. It runs on Windows, macOS, and Linux.

For heavy users, it can run two accounts at the same time, each in its own window, instead of one after another.

03

The trick: hand off before you're tired

What's the clever trick? ›

The clever part isn't juggling accounts by hand — it's doing the juggling for you, like a relay race.

claude-swap quietly watches how close each account is to its limit — the same numbers you'd see if you checked yourself.

The moment your active account nears its limit, it picks whichever other account has the most time left. Then it hands you off to that account before you ever get cut off.

It's like a relay race: the next runner starts running before the first one runs out of breath. No baton drop, no awkward pause. The race never stops. You just don't see the handoff.

It swaps you to a fresh account before the clock ever hits zero — you never even feel the wall.

04

What happens under the hood

How does it actually work? ›

One layer deeper: the words claude-swap's own documentation actually uses.

Each account's login is saved as an OAuth token — a small piece of proof that you're signed in, so you don't retype a password every time. claude-swap backs up each account's token and settings the first time you add that account.

When you switch, it swaps only the account-specific part of your login and leaves shared state alone, such as logins for extra tools connected to the assistant. On Linux and Windows, it rewrites a credential file that Claude Code re-reads whenever it changes. On macOS, credentials live in the system Keychain, which Claude Code caches for about 30 seconds before it picks up a switch.

Automatic switching runs as a background loop that checks usage every so often. It refreshes a target account's token before activating it, and holds Claude Code's own credential lock while writing, so a swap never collides with a token refresh already in progress.

05

Who actually reaches for this

Who would reach for this, and how? ›

claude-swap is for anyone using Claude Code enough to bump into its limits — which, if you're reading this, might already be you.

1 The solo builder who codes for hours Solo use ›

You code for hours with Claude Code and keep hitting its 5-hour or 7-day limit.

Turn on cswap auto once, and it watches your usage and switches accounts for you — so you can keep working without noticing the wall was ever there.

2 Two accounts, two tasks, at once Parallel work ›

Maybe you want one account grinding through a long task, and another free for quick questions in a different window.

cswap run 2 launches Claude Code as a second account in just that terminal, while everywhere else stays on your default login.

3 Scripts, servers, and teams Automation ›

On a headless server with no browser, cswap add-token registers an account straight from a setup-token or API key (a long credential string).

In a cron job (a scheduled task that runs by itself), cswap auto --once checks usage a single time and switches if needed, reporting the result in its exit code.

06

Get it running

How do I run it myself? ›

claude-swap is a command-line tool. Install it with uv (a fast Python package manager) or pipx — either works.

uv tool install claude-swap
  1. Get a package manager Make sure you have uv or pipx on your machine — small tools that install command-line programs like this one.
  2. Install the tool Run uv tool install claude-swap (or pipx install claude-swap). This puts the cswap command on your machine.
  3. Confirm it's there Run uv run cswap help — you'll see the full list of commands, including add, list, switch, and auto.
  4. Add your first account Run cswap add and log in through the browser flow; claude-swap backs up that account's login so it can switch to it later.
  5. Open the live dashboard Run cswap on its own to open the full-screen dashboard, with live 5-hour and 7-day usage bars for every account you've added.
  6. Turn on auto-switching Run cswap auto to let claude-swap watch your usage and switch you to a fresh account before you hit a limit.
  7. Go further (optional) On macOS, install the menu bar extra with uv tool install 'claude-swap[menubar]', or fine-tune behavior with cswap config.
